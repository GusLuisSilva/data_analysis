# Airline Operations Analytics

## Executive Summary
In 2022, this airline operated 98,619 flights across 235 countries. 
**Critical Finding: 66% of flights experienced delays or cancellations.**

This project identifies root causes and proposes a data-driven strategy 
to improve on-time performance.

## Key Findings
- 926 records with data quality issues
- 20 airports account for 100% of on-time failures
- Monday is worst day (67.4% out of time)
- 82% of flights are domestic (opportunity for consolidation)

## Quick Start

```bash
pip install -r requirements.txt
jupyter notebook airport_analyse.ipynb
```
